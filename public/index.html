Questions

Clear rules before checkout

Do I need to share my ESPN password?

No. FantasyIQ v1 uses public ESPN league data. Your league needs to be public for live sync.

What happens after I subscribe?

You send league details during setup, then receive a configured dashboard link and access code.

Can private leagues use it?

The dashboard can still be configured, but live draft sync requires the ESPN league to be public.

What does one subscription cover?

One account dashboard for up to three ESPN fantasy football leagues for one season, with concierge setup and support.

Requirement

Live sync requires a public ESPN league

Private ESPN league authentication is not included in this v1 concierge setup. If your league is private, the dashboard can still be configured, but live draft sync will not work until the league is public.
