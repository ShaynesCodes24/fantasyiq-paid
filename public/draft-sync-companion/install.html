Install Draft Sync Companion

The companion lets MyFantasyIQ follow ESPN draft-room pick events from your logged-in ESPN tab when ESPN does not publish live picks through the public league feed.

The Chrome Web Store version is the customer path. Use the beta download only for testing before Google approval.

1 Submit to Chrome

Upload the store package in the Chrome Developer Dashboard and wait for Google approval.

2 Add to Chrome

Once approved, customers install from the Chrome Web Store without downloading a ZIP.

3 Return to Draft Room

Refresh MyFantasyIQ, confirm the installed status, then open ESPN from the Draft Room.

Beta download is temporary. The production install should be the Chrome Web Store listing so customers only click Add to Chrome. The companion does not collect ESPN passwords or send ESPN session cookies to MyFantasyIQ. ESPN's draft security token is used locally in Chrome to connect to the active draft room and is not stored or sent to MyFantasyIQ.
