Draft Sync Companion

This is the one-time browser helper that lets MyFantasyIQ read ESPN draft-room pick events from your logged-in ESPN tab when ESPN hides live picks from its public league feed.

  1. Install the companion extension once. The Chrome Web Store link will replace this internal test page before launch.
  2. Open your MyFantasyIQ dashboard and paste the full ESPN draft URL.
  3. Click Open ESPN Draft Room. The companion starts automatically in ESPN.

Internal testing: load the public/draft-sync-companion folder as an unpacked Chrome extension. Customers should never need DevTools or console paste.
