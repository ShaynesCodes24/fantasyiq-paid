Draft Sync Companion

This page lets Chrome Web Store reviewers verify that the installed extension can run on MyFantasyIQ without requiring a live ESPN draft room.

Not installed

Install the extension, then refresh this page. The status should change to Installed.

What This Verifies

  • The MyFantasyIQ content script is active.
  • The extension can confirm installed status to MyFantasyIQ pages.
  • The test does not require ESPN credentials or a live draft room.

Data Boundaries

  • No ESPN passwords are collected.
  • No ESPN session cookies are sent to MyFantasyIQ.
  • ESPN's draft security token is used locally in Chrome and is not stored or transmitted to MyFantasyIQ.
  • Live pick-event sync requires a user-owned ESPN fantasy football draft room.
